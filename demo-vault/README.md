# OmaForge demo vault

Made-up tasks for trying OmaForge. Dates are filled in relative to today
when `omaforge --demo` copies this vault, so the copy always has something
due today, something overdue and something coming up.

`Tasks format/` holds the same kind of thing in the Obsidian Tasks plugin's
format: checkbox lines in ordinary notes, and a dashboard of ```tasks
queries. Run `omaforge --demo --tasks` to see the demo that way.
